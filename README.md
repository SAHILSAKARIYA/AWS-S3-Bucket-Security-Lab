# AWS S3 Bucket Security Lab

## Overview
This project demonstrates the implementation of security best practices for Amazon S3 buckets in AWS cloud environments. The lab focused on securing storage resources using IAM policies, bucket permissions, encryption, and logging.

## Objectives
- Configure secure AWS S3 buckets
- Apply IAM user permissions and bucket policies
- Identify and remediate public access issues
- Enable encryption and logging
- Practice least-privilege access control

## Tasks Performed
- Created and configured S3 buckets
- Configured IAM users and access permissions
- Applied bucket policies for secure access
- Blocked public access configurations
- Enabled server-side encryption
- Enabled bucket logging for monitoring

## Tools & Technologies
- AWS S3
- AWS IAM
- AWS Console

## Skills Learned
- Cloud Security Fundamentals
- AWS Identity & Access Management
- S3 Bucket Security
- Access Control Policies
- Security Monitoring
